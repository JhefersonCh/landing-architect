      02 · Contexto, tecnologías y técnicas

      Vertical, stack y técnicas

      El vertical define el contexto de negocio (psicología, objeciones, mercado). La tecnología define cómo se implementa. Ambos afectan el prompt de forma distinta.

      01 Verticales de negocio (opcional)

      Si no elegís ninguno, la IA infiere el rubro a partir de la descripción del proyecto.

      02 Tecnologías de implementación *
      03 Técnicas de diseño con IA

      Las 8 técnicas de la guía. Cada una puede activarse por separado: el prompt y el flujo de generación se arman con las que elijas.

      Cadena semilla (SSoT)

      Esta cadena decide la dirección creativa: paleta, tipografía, layout, hero, 3D y scroll. La misma cadena da siempre la misma dirección; se guarda en este navegador y se sustituye en el prompt de ejecución. Para otra dirección, generá una cadena nueva o pegá una propia.

      Vista previa de decisiones

      Concepto rector (técnica 2)

      La página ES un concepto del mundo del cliente, con su propia forma de navegarse. Idealo y elegilo acá, antes del prompt: así el prompt se arma una sola vez con el concepto elegido y los recursos (imágenes y video) lo expresan.

        Recursos generados (técnicas 4 y 5)

        Generá las imágenes y el video antes del prompt para verlos, regenerar o quitar lo que no sirva. El prompt se arma con lo que quede acá.
